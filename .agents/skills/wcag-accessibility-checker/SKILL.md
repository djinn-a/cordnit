# WCAG Accessibility Checker

## Instructions
1. Review the proposed UI component code.
2. Verify semantic HTML is used.
3. Check that all interactive elements have clear, contrasting focus states.
4. Ensure every `<img>` tag has a descriptive `alt` attribute.
5. Verify color contrast ratios for text against backgrounds comply with WCAG AA (4.5:1).
6. Reject the component if accessibility standards are missed.
