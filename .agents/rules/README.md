# Antigravity Agent Rules

This directory contains the central configuration for AI agent behavior. 
These rules strictly govern how agents read, modify, and interact with the codebase.

## Core Directives

1. **REUSE → EXTEND → CREATE**
2. **EXISTING STRUCTURE → NEW STRUCTURE**
3. **MINIMAL CHANGE → UNNECESSARY REFACTORING**
4. **DOCUMENTATION BEFORE ASSUMPTION**
5. **VERIFY BEFORE COMPLETE**

## Strict "Never" Constraints

- Never invent requirements
- Never silently change approved architecture
- Never create duplicate components
- Never create duplicate utilities
- Never create arbitrary folders
- Never delete files without verification
- Never move files without checking dependencies
- Never overwrite project knowledge blindly
