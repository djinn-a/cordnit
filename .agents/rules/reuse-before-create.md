# Reuse Before Create

Defines the strict hierarchy of component generation.

## Rule: Reuse Hierarchy
**REUSE → EXTEND → CREATE**
1. **Reuse** existing components/utilities if they meet requirements.
2. **Extend** existing components/utilities if they are close.
3. **Create** new only if absolutely necessary.

## Constraints
- Never create duplicate components.
- Never create duplicate utilities.
