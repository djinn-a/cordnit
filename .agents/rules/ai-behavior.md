# AI Behavior Rules

Defines the overarching behavioral expectations of the Antigravity agent.

## Implementation Workflow

### Before Implementation
1. Read GEMINI.md.
2. Read SESSION-STATE.md.
3. Read CURRENT-TASK.md.
4. Load only relevant documentation.
5. Inspect relevant code.
6. Search for existing implementation.

### At Completion
1. Test work.
2. Verify requirements.
3. Update relevant documentation.
4. Update AI context.
5. Update CHANGELOG.
6. Update HANDOVER when needed.

## Constraints
- Never invent requirements.
- Never silently change approved architecture.
- Never overwrite project knowledge blindly.
